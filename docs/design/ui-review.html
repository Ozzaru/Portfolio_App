Revisión del Diseño UI

Lo que está muy bien + 3 mejoras sugeridas

✓ Lo que está excelente

Dark theme financiero
Apropiado para datos financieros. Reduce fatiga visual en sesiones largas de análisis.
Sidebar con todos los módulos
La navegación refleja exactamente los 6 módulos del sistema. Coherente con la arquitectura.
Estado de fuentes de datos
Mostrar Yahoo/CoinGecko/Alpha Vantage OK o ERROR en tiempo real es esencial para confiar en los datos.

⚡ 3 Mejoras sugeridas

1. KPI cards en la parte superior
Agrega 4 tarjetas antes de los gráficos: Valor Total, P&L Hoy, Retorno Total, y # de activos. Lo primero que quieres ver al abrir la app.

2. Backtesting y Escenarios en páginas propias
El dashboard está muy denso. Los paneles de Backtesting y What-If son herramientas de análisis profundo — merecen su propia página completa, no un widget pequeño.
Dashboard mantiene:
✓ KPI cards
✓ Gráfica de rendimiento
✓ Distribución de activos
✓ Tabla de posiciones
Se mueven a su página:
→ Backtesting completo
→ Simulaciones What-If
3. Selector de período global
Un filtro de tiempo en la barra superior (1S · 1M · 3M · 1A · Todo) que afecte todas las gráficas del dashboard simultáneamente.
1S 1M 3M 1A Todo
Afecta: gráfica de rendimiento, P&L, tabla de activos

Estructura de páginas propuesta

/dashboard — KPIs + rendimiento + distribución + posiciones
/portfolio — gestión completa de posiciones y transacciones
/analytics — métricas avanzadas, benchmarks, correlaciones
/backtest — probador de estrategias completo
/scenarios — simulaciones what-if y estrés
/alerts — centro de alertas
/data-sources — fuentes de datos y entrada manual
/settings — configuración de cuenta
